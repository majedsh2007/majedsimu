# منصة الفيزياء — نظام دخول حقيقي

تم دمج جميع ملفات `physics.zip` داخل `public/`، مع حماية خادمية لجميع ملفات المنصة والمحاكاة.

## التشغيل
يتطلب Node.js 18+ (يفضل 20+).

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## حساب المدير الأول
افتراضيًا:
- المستخدم: `admin`
- كلمة المرور: `1234`

غيّرها قبل النشر باستخدام متغيرات البيئة:
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `SESSION_SECRET`

مثال:
```bash
ADMIN_USERNAME=teacher ADMIN_PASSWORD='كلمة-مرور-قوية' SESSION_SECRET='سر-عشوائي-طويل' npm start
```

## الإدارة
بعد تسجيل الدخول كمدير:
`/admin.html`

يمكن إنشاء الطلاب وتفعيل/إيقاف الحسابات وحذفها.

## الحماية
الخادم يمرر ملفات `public` عبر `requireAuth`، لذلك الرابط المباشر لأي محاكاة يحتاج جلسة دخول صالحة.

كلمات المرور مخزنة كـ bcrypt hashes، وليس كنص صريح.

## النشر
استخدم استضافة Node.js مع HTTPS، ولا تستخدم بيانات الدخول الافتراضية في الموقع المنشور.
